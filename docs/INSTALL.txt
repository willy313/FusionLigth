Installing Lumen in Clickteam Fusion 2.5
=========================================

Close Fusion first. Then copy the two files, keeping their folder names:

  Extensions\Unicode\Lumen.mfx        ->  <Fusion folder>\Extensions\Unicode\
  Data\Runtime\Unicode\Lumen.mfx      ->  <Fusion folder>\Data\Runtime\Unicode\

(<Fusion folder> is usually C:\Program Files (x86)\Clickteam Fusion 2.5 or the Steam equivalent.)
Windows may ask for administrator rights. If the files come from a downloaded zip, right-click each
one, Properties, tick Unblock.

Start Fusion: "Lumen" appears in the Insert Object dialog.

How it works in one minute
--------------------------
* Put ONE Lumen object in the frame, on a layer ABOVE what you want darkened. It sizes itself to the
  window and follows the camera; its editor size does not matter. Objects on layers above it stay bright (HUD).
* Everything is dark until you add light: "Set ambient light level" raises the base brightness.
* Lights are made with "Create or update light". Give each light an ID (or -1 to get one automatically
  and read it with LastCreatedLightID). Creating a light with an existing ID updates it.
* Shadows: a light is only blocked by obstacles on its own "shadow layer" (a Fusion layer number).
    - "Make object cast shadows": choose any object (active objects, quick backdrops that appear in the
      event editor). Fusion runs the action once for every instance. It follows the object when it moves.
    - "Add obstacle rectangle": a fixed rectangle in frame pixels. Use this for true backdrop objects, which
      Lumen cannot read yet.
* "Create light on object" makes a light that follows an object and disappears with it. It runs once for every
  instance of the object you pick, so give it -1 as the light ID.

First test (about two minutes)
------------------------------
1. Set Display mode to Direct3D 11 (Application properties, Runtime options).
2. Insert a Lumen object. Insert two active objects (for example squares) as walls.
3. Events:
     Start of frame:  Lumen: Set ambient light level to 0
                      Lumen: Make <your wall object> cast shadows on shadow layer 1
                      Lumen: Create or update light 1 at X=320, Y=240 (radius 250, brightness 1, shadow layer 1)
     Always:          Lumen: Move light 1 to X=XMouse, Y=YMouse
4. Run. Expect darkness with a smooth circle of light following the mouse, and a shadow behind each wall.

If the application crashes without any message
----------------------------------------------
Lumen has three ways to put the darkness on the screen (0 alpha lock, 1 alpha surface, 2 rectangles). The SDK does not
say which of them works on your machine, so Lumen finds out by itself:

  * On the first run it tries method 0 and writes "tried 0" to  %TEMP%\Lumen-method.txt.
  * If the application then crashes, JUST START IT AGAIN. Lumen sees "tried 0" without "ok 0", skips that method
    and tries the next one. After at most two more starts it is on a method that does not crash.
  * The first complete draw writes "ok N", and from then on that method is used every time.
  * A new Lumen build forgets these notes and starts again at method 0.

If it still crashes, send me  %TEMP%\Lumen-debug.log  (press Win+R, type %TEMP%\Lumen-debug.log, Enter). The LAST
line is the step that was running. The file has at most 80 short lines and is rewritten at every start.
To start the method search over, delete  %TEMP%\Lumen-method.txt.

To try a method by hand, use the action  Debug: render options  with method 0, 1 or 2 (-1 = automatic). Say which
methods look right: darkness with soft light circles, no tint, no blocks.

What to report back
-------------------
 * It works / it crashes / it is not visible. For a crash, the exact text of the error box.
 * The text of  Lumen.DebugInfo$(  shown in a String object (timings and counts).
 * Does the shadow appear behind the walls? Is the edge of the light smooth or blocky?
 * Try the "Pixel size" property (1, 2, 4) or the action "Set lightmap pixel size". 1 is sharpest; larger values
   are faster and are smoothed when stretched.
 * If the picture looks wrong (all black, or a tint), try "Debug: render options" with smooth edges 1, copy-alpha 0,
   method 0, then 1, then 2 (invert blend 0), then 2 with invert blend 1. Say which looks right.
 * Frame rate with 1 light and with 50 lights.
